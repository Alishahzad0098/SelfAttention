# What I Learned During My Internship

During my internship, I explored how GPT models generate text and how ontologies represent knowledge.

## GPT and Attention
- **Self-attention** — I learned how GPT weighs the relevance of earlier tokens when interpreting the current token.
- **Multi-head attention** — I learned how several attention heads work in parallel to capture different relationships between tokens.

## Ontology Development

- **Designing an ontology** — I learned how to identify the main concepts in a domain, define their properties, and describe how they relate to one another. For example, a university ontology can represent the relationship `Student → enrolls in → Course`.
